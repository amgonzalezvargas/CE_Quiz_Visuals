Case Study & Quiz: The Movie-Finder Research Agent

0/30 points

An autonomous research agent is tasked with tracking down an obscure animated film based on four fragmented childhood clues: a grumpy brass pocket watch, a sky-bridge steam train, a pre-1998 European festival prize, and a score by a former jazz trumpeter.

To prevent context rot, the harness implements context management hooks: deduplication, extraction, truncation, and compaction. Step through the failure modes below to observe how indiscriminate truncation creates re-search loops, how compaction drift drops negative constraints, and how aggressive sentence extraction strips essential caveats.

Question 1:

10 points

During the movie search task, the agent's context window fills up with older turns, triggering a brute-force truncation hook that deletes the early turn where doc_5 was retrieved and analyzed. Later, the agent cannot find the festival data in its context window and executes a redundant search for the festival prize. Which context management problem does this scenario illustrate?

Question 2:

10 points

When the movie agent goes down a dead-end path searching 1990s Japanese anime films, a compaction hook summarizes the history into a handoff summary. Due to a poorly tuned compaction prompt, the summary drops the critical detail that the anime path was abandoned, causing the agent to waste steps re-running searches down the same failed path. Which context management mechanism is responsible for this failure?

Question 3:

10 points

The movie agent searches for the soundtrack composer clue using an extraction hook equipped with an LLM judge. The judge evaluates the retrieved review article strictly against the isolated search query, stripping out a critical disclaimer about an electronic synthesizer score and leaving only the isolated sentence about a jazz trumpeter. As a result, the agent forms false confidence and selects the wrong candidate. Which technical limitation of extraction does this scenario demonstrate?
